# 백운교회 GitHub Pages 홈페이지 - 메뉴 링크 수정본

이 버전은 메뉴를 누르면 실제 HTML 페이지로 이동합니다.

- 교회소개 → `about.html`
- 예배안내 → `worship.html`
- 말씀 → `sermon.html`
- 사역 → `ministry.html`
- 교회이야기 → `stories.html`
- 오시는 길 → `location.html`
- 섬기는 사람들 → `leaders.html`
- 교회앨범 → `gallery.html`

## 업로드 방법
GitHub 저장소의 기존 홈페이지 파일을 이 폴더의 파일들로 교체합니다. 특히 `index.html`만 올리지 말고 **모든 html 파일, style.css, script.js, .nojekyll**을 함께 올려야 메뉴가 정상 연결됩니다.

GitHub Pages 설정은 보통 `Settings → Pages → Deploy from a branch → main / root`입니다.

상대경로(`about.html`)를 사용했기 때문에 `사용자명.github.io/저장소명/` 형태의 Project Pages에서도 작동합니다.
